# مسلسلاتي — صفحة مسلسلات مقيّدة للتابلت

صفحة بسيطة تعرض قوائم تشغيل وقنوات يوتيوب محددة فقط، بدون بحث ولا شورتس ولا اقتراحات.

- الرابط: https://a-ghareeb86.github.io/tablet-series-player/
- قائمة المسلسلات والرمز السري تُحفظ على التابلت فقط (في المتصفح)، ولا شيء منها في هذا المستودع.
- الإدارة: ضغط مطوّل 5 ثوانٍ على الزاوية العليا اليسرى ← الرمز السري.
- لإضافة حلقات: أضفها إلى قائمة التشغيل في يوتيوب (غير مدرجة أو عامة)، فتظهر تلقائيًا.

الملفات: `index.html` (الصفحة)، `manifest.webmanifest` (للتثبيت على الشاشة الرئيسية)، `icon.svg` (الأيقونة).
